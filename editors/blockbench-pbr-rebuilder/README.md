# SyncCraft PBR Texture Rebuilder (Blockbench 5 Plugin)

Installable Blockbench 5 plugin for **importing, previewing, rebuilding, and baking PBR textures** generated by `synccraft.texgraph` (or any Minecraft LabPBR 1.3 / Bedrock RTX MER pack).

## Installation in Blockbench 5
1. Open Blockbench 5 -> `File` -> `Plugins...` -> **Load Plugin from File** (top-right icon).
2. Select `synccraft_pbr_rebuilder.js`.
3. Use the four actions added under **`Tools`**:
   - **SyncCraft PBR: Import Bundle (`.synccraft.pbr.json`)** — loads either a self-contained embedded manifest or sibling `_n.png` / `_s.png` / `_mer.png` / `_normal.png` / `_emissive.png` files.
   - **SyncCraft PBR: Toggle Live Three.js PBR Viewport** — unpacks LabPBR 1.3 or Bedrock MER into crisp `NearestFilter` Three.js `MeshStandardMaterial` maps with 3-point studio lighting (cleanly restores original Blockbench materials when toggled off).
   - **SyncCraft PBR: Rebuild & Bake Studio Texture...** — interactive Cook-Torrance GGX baking dialog with presets (`Studio Hero`, `Dramatic Obsidian Rim`, `High Noon Daylight`, `Moonlit Obsidian`) and live sliders for Light Azimuth/Elevation, Normal Strength, Specular/Metallic Sheen, Contact AO, Wing SSS, and Emissive Glow — works **100% offline** inside Blockbench with full `Undo` support!
   - **SyncCraft PBR: Live Re-Run TexGraph via Bridge** — connects to optional `synccraft serve-blockbench` (`http://127.0.0.1:18765/pbr_rebuild`) to re-bake 3D mesh maps and re-evaluate a `.texgraph.json` recipe live.
